# Project-UAS
# Sistem Perhitungan Biaya Penitipan Kucing

Aplikasi console berbasis TypeScript untuk membantu kasir penitipan kucing yang menyimpan banyak transaksi dalam array di memori dan menyediakan fitur Create, Read, Update, Delete, serta Search dalam mencatat transaksi, menghitung biaya secara otomatis, serta mengelola data transaksi agar lebih mudah dan teratur.

## Daftar Fitur

- Menu utama (berulang sampai keluar)
- Create (tambah data)
- Read (tampil semua data dan detail berdasarkan ID)
- Update (ubah data)
- Delete (hapus data dengan konfirmasi Y/N)
- Search (kata kunci dan filter)
